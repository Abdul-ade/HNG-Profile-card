# HNG-Profile-card
A simple page displaying a user's profile which includes name, picture etc.

*Display user's profile picture
*Show user's name and short bio
*Link to user's social media profiles
*List user's hobbies and interests
*List user's dislikes

# Technologies Used
*HTML5
*CSS3
*Javascript

# Getting Started
1. Clone the repository: `git clone https://github.com/Abdul-ade/HNG-Profile-card`
2. Open the `HNGProfile.html` file in a web browser to view the profile card.
